## 2. Inviolable Agent Guardrails

1. **No Silent Recomputations**: The GPU agent must **never** recalculate donor splits, HVGs, PCA projections, or graphs. If any artifact hash does not match, execution must halt immediately.
2. **Immutable Feature Matrix ($X$)**: Every GNN evaluated on a split must consume the exact same precomputed 50-dim PCA matrix ($X_{\text{train}}, X_{\text{val}}, X_{\text{test}}$) generated by the CPU pipeline. No additional z-scoring, log-transformations, or feature modifications are permitted.
3. **Strict Inductive Connectivity**: Message passing must strictly respect partition boundaries:
   - **Training Phase**: `train -> train` edges only (reference graph).
   - **Validation Phase**: `train -> val` bipartite query edges only.
   - **Test Phase**: `train -> test` bipartite query edges only.
   - **Disallowed Edges**: 0 query $\to$ query edges, 0 query $\to$ train edges. Validation/test nodes must never exchange messages with each other or propagate information back to training nodes.
4. **Strict Label Isolation**: The `GraphBundle` and PyG `Data` object store labels **exclusively for training nodes** ($y_{\text{train}}$). Validation and test labels are stored in separate evaluation arrays and must never enter the model forward graph.
5. **Matched-Seed Comparison Invariant**: Graph lift must be computed strictly by comparing GNN Seed $S$ against the matched MLP baseline run with the identical Seed $S$, split hash, feature manifest hash, and label vocabulary.

## 6. How the GPU Agent Should Load and Consume Graphs

The GPU agent loads precomputed artifacts directly into PyTorch Geometric `Data` structures using standard helper methods:

```python
import torch
from scgraph_bench.graph.schema import GraphBundle
from scgraph_bench.preprocessing.schema import PreprocessedBundle

# 1. Load precomputed features and graph bundle
prep_bundle = PreprocessedBundle.load(
    "artifacts/preprocessed/stephenson_2021_healthy_pbmc/site_stratified_seed42"
)
graph_bundle = GraphBundle.load(
    "artifacts/graphs/stephenson_2021_healthy_pbmc/site_stratified_seed42/pca_knn_k20_unweighted"
)

# 2. Concatenate node feature blocks [Train (38,692), Val (21,759), Test (18,508)]
X_all = np.vstack(
    [
        prep_bundle.X_pca_train,
        prep_bundle.X_pca_val,
        prep_bundle.X_pca_test,
    ]
)

# 3. Create PyG Data object (Strict Label Isolation: only train labels passed)
data = graph_bundle.to_pyg_data(
    x=X_all,
    y_train_only=prep_bundle.train_labels,
)

# 4. Move to GPU device
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
data = data.to(device)
```

## 7. Target GNN Architectures & Training Specifications

### A. Model Specifications
1. **GCN (`GCNConv`)**:
   - Input: $D=50$, Hidden: $H=128$, Layers: 2, Output: $C=12$.
   - Activation: ReLU, Dropout: 0.2, LayerNorm or BatchNorm1d after first conv.
2. **GraphSAGE (`SAGEConv`)**:
   - Aggregation: `mean`, Hidden: $H=128$, Layers: 2.
   - Activation: ReLU, Dropout: 0.2.
3. **GATv2 (`GATv2Conv`)**:
   - Attention heads: 4 ($4 \times 32 = 128$), Layers: 2.
   - Activation: ELU, Dropout: 0.2.

### B. Hardware & Memory Footprint
- Full node feature tensor: $78,959 \times 50 \times 4\text{ bytes} \approx 15.8\text{ MB}$.
- Edge index tensor ($2 \times 2,703,044 \times 8\text{ bytes}$): $\approx 43.2\text{ MB}$.
- Total GPU memory required for full-graph training is $< 250\text{ MB}$. Full-graph GPU forward passes run comfortably on any modern GPU (RTX 3090/4090, A100, Apple Silicon MPS, or Kaggle T4).

### C. Optimization & Early Stopping Protocol
- Optimizer: AdamW (`lr=0.001`, `weight_decay=1e-4`).
- Loss: CrossEntropyLoss on `train_mask` nodes.
- Validation: Macro-F1 computed on `val_mask` nodes after every epoch.
- Early Stopping: `patience=50` epochs on validation Macro-F1 (max 500 epochs).

## 8. Matched Graph Lift Computation Protocol

For each GNN run (seed $S$, graph $G$):
1. Compute test partition metrics using `compute_evaluation_summary(...)`.
2. Load the corresponding MLP baseline run with the **exact same seed $S$**.
3. Call `compute_matched_graph_lift(gnn_summary, mlp_summary, gnn_manifest, mlp_manifest, graph_name)`.
4. Log results to `LocalMLflowTracker` and aggregate with `ResultsAggregator`.

Formula:
$$\Delta_{\text{lift}} = \text{Macro-F1}(\text{GNN}_{\text{seed } S}) - \text{Macro-F1}(\text{MLP}_{\text{seed } S})$$
