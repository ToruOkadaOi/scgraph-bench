# AGENTS.md: Pair Programming & Agent Collaboration Guidelines

## 1. Division of Responsibility

| Dimension | CPU Implementation Agent (Current) | GPU Training Agent (Subsequent) |
| :--- | :--- | :--- |
| **Scope** | Repository infrastructure, dataset prep, frozen splits, preprocessing, graph construction, graph diagnostics, classical baselines, aggregation, handoff. | Model training on CUDA (GNN architectures, large MLP sweeps, hyperparameter tuning). |
| **Hardware Target** | CPU-only, lightweight memory footprint, deterministic execution. | CUDA / GPU clusters. |
| **Artifact Role** | **Producer**: Creates immutable frozen splits, fixed feature matrices ($X$), serialized `GraphBundle` objects, and baseline results. | **Consumer**: Consumes precomputed artifacts strictly without regenerating features or modifying graphs. |
| **Testing** | Rigorous unit/integration test coverage with synthetic fixtures. | Evaluation against frozen benchmark splits and comparative graph lift. |

---

## 2. Inviolable Agent Guardrails

1. **No Silent Recomputations**: The GPU agent must never recalculate splits, PCA projections, or graphs. If an artifact is corrupt or missing, execution must halt with a validation error.
2. **Immutable Feature Invariant**: Every model evaluated on a split must consume the exact same $X$ matrix generated by the CPU preprocessor.
3. **No Label Leakage**: Graph building routines cannot accept cell-type labels.
4. **Deterministic Random Seeds**: All stochastic processes must be controlled by the centralized seed utility.
