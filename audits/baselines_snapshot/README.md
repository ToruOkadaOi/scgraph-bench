# Baseline Evidence Snapshot

Immutable record of the non-graph baseline runs that serve as the matched reference
for all graph-lift computations on this split.

- **Dataset / Split**: `stephenson_2021_healthy_pbmc` / `site_stratified_seed42`
  (12/6/5 site-stratified donor hold-out; 38,692 / 21,759 / 18,508 cells)
- **Generated by**: `uv run python scripts/run_mlp_seed_sweep.py` (MLP, seeds
  7/17/42/73/101; the seed-42 run additionally mirrors to legacy `mlp/`) and
  `scripts/train_logistic_regression.py` (logistic_regression)
- **Code version**: git commit `a91fdf0` (instrumented sweeps, post-delivery-28439e6f045c)
- **Hardware**: local Apple Silicon (MPS for MLP training), torch 2.13.0
- **Reference result**: MLP test macro-F1 = 0.9026 ± 0.0015 across 5 seeds
  (per-seed: 0.9011 / 0.9041 / 0.9012 / 0.9041 / 0.9025)

Per-run contents (text only; probability/embedding tensors excluded by policy):

| File | Description |
|---|---|
| `run_manifest.json` | Provenance manifest: hashes of split/features/preprocessing/labels, config hash, device telemetry |
| `metrics_summary.json` | Full train/val/test evaluation summaries incl. per-class and per-donor breakdowns |
| `confusion_matrix_test.csv` | Test-partition confusion matrix |
| `tidy_metrics.csv` | Tidy metric records as consumed by the aggregation engine |

Note: bit-exact reproduction across torch versions is not guaranteed; these files are
the canonical record of the numbers quoted in benchmark conclusions.
